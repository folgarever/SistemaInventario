Cómo leer este manual Cada sección corresponde a un enlace del menú superior. Los botones y campos aparecen en negrita tal como se ven en pantalla, y las capturas muestran las pantallas reales de la aplicación. Los recuadros verdes son consejos y los rojos, avisos importantes.

1. Qué es y cómo entrar

El Sistema de Inventario es una aplicación web para administrar la mercadería de una tienda: qué productos tienes, cuánto cuestan, cuánto ganan, cuánto hay en existencia y qué necesitas reponer. Funciona en la nube, así que puedes usarla desde la computadora o el celular.

1.1 Crear la cuenta

  1. Abre la dirección sistemainventario-f.vercel.app en el navegador.
  2. En la pantalla de acceso, elige la opción Crear cuenta.
  3. Completa tus datos: nombres, apellidos, correo electrónico, nombre de usuario y contraseña.
  4. Confirma el registro y ya puedes iniciar sesión con tus credenciales.

1.2 Iniciar sesión

  1. Escribe tu Usuario o correo (sirve cualquiera de los dos).
  2. Escribe tu Contraseña.
  3. Pulsa Iniciar sesión. Entrarás directo al Panel.

1.3 Recuperar la contraseña

  1. En la pantalla de acceso, elige ¿Olvidaste tu contraseña?.
  2. Escribe tu correo y envía la solicitud.
  3. Revisa tu correo, abre el enlace de restablecimiento y define una contraseña nueva.
Importante Nadie del equipo puede ver tu contraseña. Si la pierdes, solo se puede restablecer desde el enlace que llega a tu correo.

1.4 Mi perfil

Desde el enlace Perfil del menú puedes actualizar tus datos personales, cambiar la contraseña, activar o desactivar los avisos de stock bajo y eliminar tu cuenta. Se detalla en la sección 8.

2. Panel

El Panel es la primera pantalla al entrar. Muestra el estado general del negocio de un vistazo.

2.1 Tarjetas de resumen

TarjetaQué muestra
Valor del inventarioCuánto dinero representa la mercadería que tienes, a precio de costo.
Ganancia potencialCuánto ganarías si vendieras todo lo que tienes, según los precios actuales.
ProductosCuántos productos tienes registrados.
AlertasCuántos productos están agotados o con bajo stock.

2.2 Alertas de stock

Lista los productos que necesitan atención porque están Agotado o Bajo stock. Desde ahí puedes ir a Productos o a Lista de compra para reponerlos.

2.3 Últimos movimientos

Muestra las entradas, salidas y ajustes más recientes, con su fecha. Es el mejor lugar para confirmar que un registro quedó guardado.

Consejo Usa el botón Exportar PDF del Panel para guardar o compartir el resumen del negocio. Todos los gráficos de los PDF se generan dentro del documento.

3. Productos

En Productos se administra el catálogo: cada artículo con su código, costo, precio de venta, ganancia y existencias.

3.1 Crear un producto

  1. Pulsa Nuevo producto.
  2. Escribe el Nombre y el SKU / Código (el código interno que tú elijas).
  3. Define la Unidad de medida (unidad, kg, litro, caja…). Se sugiere una lista, pero puedes escribir la que necesites.
  4. Elige la Categoría y el Proveedor. Si no existen, usa el botón + Nueva / + Nuevo para crearlos sin salir del formulario.
  5. Completa Precio de compra, Precio de venta y Stock mínimo.
  6. Opcionalmente agrega una Descripción y guarda.

Mientras escribes los precios, el sistema te muestra la ganancia por unidad y el margen sobre el precio de venta.

Existencias Al crear un producto, las existencias empiezan en cero. Las existencias no se editan a mano: se mueven registrando compras, ventas o ajustes (sección 4), de modo que siempre queda un historial confiable.

3.2 Buscar, filtrar y ordenar

  • Buscar por nombre o SKU.
  • Filtrar por Categoría o por Proveedor.
  • Marcar Solo bajo stock para ver lo que hay que reponer.
  • Marcar Mostrar inactivos para incluir los productos desactivados.
  • Pulsar Limpiar filtros para volver a ver todo.
  • Hacer clic en el título de una columna (SKU, Producto, Categoría, Costo, Precio venta, Ganancia, Existencias, Estado) para ordenar; un segundo clic invierte el orden.

3.3 Acciones de cada producto

AcciónQué hace
EditarCambia nombre, precios, categoría, proveedor, stock mínimo o descripción.
Desactivar / ActivarOculta el producto de las operaciones sin borrarlo. Los inactivos se ven con la casilla Mostrar inactivos.
EliminarBorra el producto. Úsalo solo si nunca se usó.

El botón Exportar PDF genera la lista con el orden y los filtros que tengas aplicados en pantalla.

Estados de stock Disponible (por encima del mínimo), Bajo stock (en o por debajo del mínimo) y Agotado (cero). Estos estados alimentan las alertas y la lista de compra.

4. Movimientos

En Movimientos se registra todo lo que entra y sale del inventario. Cada operación deja registro en el historial y no se puede modificar después.

OperaciónEfecto en el stockCuándo usarla
Registrar compraSube el stockCuando recibes mercadería de un proveedor.
Registrar ventaBaja el stockCuando vendes productos.
Ajustar existenciasCorrige el stockCuando el conteo real no coincide con el sistema.
Registrar devoluciónReintegra el stockCuando un cliente devuelve un producto.

4.1 Registrar una compra (entrada)

  1. Pulsa ↑ Registrar compra.
  2. Elige el Proveedor (opcional) y la Fecha.
  3. Agrega una o varias líneas: producto, cantidad y costo unitario.
  4. Usa + Agregar producto para sumar líneas y la ✕ para quitar una.
  5. Revisa el Total de la compra, agrega observaciones si quieres y pulsa Registrar compra.

4.2 Registrar una venta (salida)

  1. Pulsa ↓ Registrar venta.
  2. Elige el Motivo (por ejemplo, venta) y la Fecha.
  3. Agrega las líneas con producto y cantidad. Junto a cada producto verás las existencias disponibles.
  4. Confirma el Total de la venta y pulsa Registrar venta.
Sin stock negativo El sistema nunca deja vender más de lo que hay. Si intentas vender más que las existencias, te lo indicará para que corrijas la cantidad.

4.3 Ajustar existencias

  1. Pulsa ⇄ Ajustar existencias.
  2. Elige el Producto.
  3. Escribe las Existencias contadas (lo que realmente hay).
  4. Elige el Motivo y la Fecha. El sistema te muestra la diferencia antes de guardar.

4.4 Registrar una devolución

Pulsa ↩ Registrar devolución, elige el producto, la cantidad y el motivo. El producto vuelve al stock y queda registrado en el historial como devolución.

4.5 Mermas

Una merma es mercadería que se pierde sin venderse. Se registra como una salida con motivo Dañado o Perdido. Después puedes verlas en el reporte de Mermas (sección 7).

4.6 Historial

Debajo de los formularios está el historial de movimientos, con fecha, tipo, producto, cantidad y motivo. Los registros son inmutables: para corregir algo se hace un nuevo movimiento (por ejemplo, un ajuste), nunca se edita el anterior.

5. Conteo físico

El Conteo físico sirve para recorrer tus productos, anotar lo que hay realmente y generar de una sola vez los ajustes de las diferencias.

5.1 Definir la frecuencia

  1. En Frecuencia de conteo, elige cada cuánto cuentas el inventario: diario, semanal o quincenal.
  2. El sistema recuerda tu elección y te muestra la fecha del último y del próximo conteo.
  3. Si la fecha ya pasó, verás un aviso en rojo recordándote que toca contar.

5.2 Contar

  1. Usa el buscador para encontrar un producto por nombre o SKU.
  2. Escribe la cantidad real en la columna Contado. La columna Sistema muestra lo que dice el sistema.
  3. La columna Diferencia se calcula sola: Coincide, sobrante (+) o faltante (−).
  4. Arriba verás cuántos productos llevas contados y cuántos tienen sobrante o faltante.
  5. Pulsa Registrar conteo para aplicar los ajustes de las diferencias.

El botón Limpiar borra lo que escribiste sin registrar nada, y Exportar PDF genera una hoja con el conteo, respetando la búsqueda activa.

Consejo Cuenta por zonas o estantes y registra el conteo al terminar cada uno. Así el trabajo queda guardado aunque cierres la aplicación.

6. Lista de compra

La Lista de compra reúne lo que necesitas comprar. Combina los artículos que agregas a mano con las recomendaciones automáticas de los productos con bajo stock.

6.1 Actualizar recomendaciones

Al abrir la página, y cada vez que pulses Actualizar, el sistema revisa el inventario y agrega los productos con bajo stock como líneas recomendadas. La cantidad sugerida repone hasta el doble del stock mínimo de cada producto.

6.2 Agregar un artículo a mano

  1. Pulsa Agregar artículo.
  2. Escribe el Artículo (lo que necesitas comprar, aunque no sea un producto del inventario).
  3. Indica la Cantidad y la Unidad.
  4. Opcionalmente, el Proveedor y una Nota (marca, tamaño, detalle).
  5. Pulsa Agregar.

6.3 Trabajar la lista

ElementoQué hace
CompradoMarca la línea como ya comprada; se muestra atenuada.
CantidadAjusta cuánto necesitas de esa línea.
OrigenIndica si es una recomendación de Bajo stock o un artículo Manual.
QuitarElimina los artículos manuales.
DescartarOculta una recomendación sin borrarla.
Restaurar descartadosVuelve a mostrar las recomendaciones descartadas.
Quitar compradosLimpia de una vez todo lo marcado como comprado.

Los artículos se agrupan por proveedor y arriba verás los totales: Artículos, Por comprar, Comprados y Costo estimado. Puedes buscar por artículo, SKU o proveedor, y marcar Solo por comprar para ocultar lo ya comprado. El botón Exportar PDF genera la lista para llevarla al proveedor.

Dónde se guarda La lista de compra se guarda en tu navegador, no en el inventario. Es una lista de trabajo: no cambia las existencias hasta que registres la compra correspondiente en Movimientos.

7. Reportes

En Reportes encontrarás cinco pestañas. Puedes cambiar de pestaña y, según el reporte, filtrar por rango de fechas con Desde y Hasta o con los atajos Este mes y Mes anterior.

Ventas y ganancia

Operaciones, unidades vendidas, ingreso, ganancia estimada y margen, con el detalle por producto.

Inventario

Valor de la mercadería y existencias. Puedes ver Solo bajo stock o Incluir inactivos.

Reposición

Productos con stock bajo o agotado y la cantidad sugerida a comprar, agrupados por proveedor.

Mermas

Productos dañados o perdidos en el periodo, con su costo.

Rotación

Qué productos se mueven y cuáles no. Marca Solo sin movimiento para detectar lo que está parado.

Sobre la ganancia La ganancia es una estimación: se calcula con el precio de venta y el costo actuales de cada producto, no con el precio que tenía en el momento de la venta.

El botón Exportar PDF genera el reporte de la pestaña activa, con sus filtros y sus gráficos incluidos.

8.1 Mi perfil

SecciónQué puedes hacer
Datos personalesActualizar nombres, apellidos, correo y nombre de usuario.
Cambiar contraseñaDefinir una contraseña nueva (pide la actual y su confirmación).
Avisos de stock bajoActivar o desactivar los avisos de productos con bajo stock.

Ten cuidado Eliminar la cuenta es permanente y no se puede deshacer. Asegúrate de haber exportado antes los reportes que necesites.

8.2 Tema claro y oscuro

En la barra superior hay un botón para alternar entre tema claro y tema oscuro. Tu preferencia se recuerda para la próxima visita.

8.3 Instalar como aplicación

El sistema funciona como aplicación web instalable (PWA). En el navegador de tu computadora o celular busca la opción Instalar aplicación o Agregar a pantalla de inicio. Se abrirá en su propia ventana, como cualquier otra app.

Cuando se publique una versión nueva, la aplicación te avisará para que la actualices.

8.4 En el celular

Todas las pantallas son adaptables: en teléfonos, el menú se convierte en un botón que despliega los enlaces. Las tablas se pueden desplazar horizontalmente.

9. Preguntas frecuentes

¿Por qué no puedo vender más de lo que tengo?

El sistema impide el stock negativo. Si necesitas vender algo que no figura, primero registra una compra o un ajuste que refleje la mercadería real.

¿Puedo usar cantidades con decimales?

Sí. Las cantidades admiten decimales, ideal para productos que se venden por peso o fracción (por ejemplo, 0,5 kg).

¿Se puede cambiar el precio de una venta ya registrada?

No. El historial es inmutable para que las cuentas sean confiables. Si hubo un error, se registra un nuevo movimiento que lo corrija.

¿Cómo sé qué tengo que comprar?

Revisa el Panel y las Alertas de stock, o abre directamente la Lista de compra, que ya trae las recomendaciones de los productos con bajo stock.

¿Dónde quedan los archivos que exporto?

Los PDF se descargan a la carpeta de descargas de tu navegador, con un nombre que incluye la fecha.

¿Qué diferencia hay entre ajustar existencias y hacer un conteo?

El ajuste corrige un solo producto y es para casos puntuales. El conteo físico recorre todos los productos y genera los ajustes de las diferencias de una sola vez.

¿Mis datos están seguros?

Cada cuenta accede solo a su propio inventario, protegido con inicio de sesión. Para más detalle, consulta el Aviso de privacidad enlazado en la aplicación.
